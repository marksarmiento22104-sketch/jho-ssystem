HOW TO ADD VARIABLES IN RAILWAY
================================================================================

Method 1: One by One (Easier)
------------------------------------------------------------------------
1. Go to your Backend service in Railway
2. Click "Variables" tab
3. Click "New Variable"
4. Add each variable:
   - Name: APP_NAME
   - Value: RailynStore
5. Click "Add"
6. Repeat for all variables

Method 2: Raw Editor (Faster)
------------------------------------------------------------------------
1. Go to your Backend service in Railway
2. Click "Variables" tab
3. Click "RAW Editor" button
4. Paste all variables at once (from template above)
5. Click "Update Variables"

================================================================================
COMMON MISTAKES TO AVOID
================================================================================

❌ DON'T manually replace ${{MySQL.MYSQLHOST}} with actual values
   ✅ Leave it as ${{MySQL.MYSQLHOST}} - Railway fills this automatically

❌ DON'T put https:// in SANCTUM_STATEFUL_DOMAINS
   ✅ Use only the domain: frontend-url.railway.app

❌ DON'T forget https:// in CORS_ALLOWED_ORIGINS
   ✅ Use full URL: https://frontend-url.railway.app

❌ DON'T forget the DOT in SESSION_DOMAIN
   ✅ Must be: .railway.app (with the dot in front)

❌ DON'T use APP_DEBUG=true in production
   ✅ Keep it false for security

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "No application encryption key has been specified"
Fix: Make sure APP_KEY is set correctly with the base64: prefix

Issue: "SQLSTATE[HY000] [2002] Connection refused"
Fix: Check DB_* variables are using ${{MySQL.*}} syntax

Issue: "CORS policy error" in browser console
Fix: Make sure CORS_ALLOWED_ORIGINS includes https://

Issue: "419 CSRF token mismatch"
Fix: Check these 3:
  - SESSION_DOMAIN=.railway.app (with dot!)
  - SESSION_SECURE_COOKIE=true
  - SESSION_SAME_SITE=none

Issue: "401 Unauthorized" on login
Fix: Make sure SANCTUM_STATEFUL_DOMAINS matches frontend domain (no https://)
